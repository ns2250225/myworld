# 马清雄的方块小屋 🧱

一个「我的世界」风格的 3D 个人主页：用方块搭出一座落地玻璃大平层、后院泳池和街机厅，走进世界里就能认识我、看我做的 22 款网页小游戏。

纯前端、单文件实现，克隆下来用浏览器打开 `index.html` 即可游玩。

## ✨ 特性

- 🏠 **像素方块世界**：落地玻璃大平层（书房、客厅吧台、作品展廊、主卧，平屋顶带太阳能板与露台）、泳池、花田、路灯等场景均由程序化生成的方块搭建，材质内置于页面，无需额外资源
- 🕹️ **街机游戏厅**：22 台「游戏机」对应我的 22 款网页游戏，靠近按提示点击即可打开对应作品
- 🌗 **昼夜与天气**：时间流动、日落月升，还可以用指令切换天气与放烟花
- 💬 **聊天指令系统**：按 `T` 打开聊天框，支持 `/help`、`/tp`、`/time`、`/weather`、`/give`、`/summon`、`/fireworks`、`/github` 等指令
- 📱 **移动端适配**：点击地面走路、单指旋转视角、双指缩放，手机上也能逛
- 🔊 **音效与 BGM**：基于 Web Audio API 合成，无需加载外部音频文件

## 🛠️ 技术栈

- **[Three.js](https://threejs.org/)**（WebGL）：3D 场景渲染，`OrbitControls` 视角控制，`mergeGeometries` 合并几何体优化性能
- **Web Audio API**：程序化合成音效与背景音乐
- **原生 JavaScript + CSS**：单文件 `index.html`（约 220 KB），零依赖、零构建，字体使用 Press Start 2P / VT323 像素字体

## 🚀 本地运行

无需安装任何依赖，任选一种方式：

```bash
# 直接用浏览器打开
open index.html

# 或者起一个本地静态服务（推荐，路径行为与线上一致）
python3 -m http.server 8000
# 然后访问 http://localhost:8000
```
